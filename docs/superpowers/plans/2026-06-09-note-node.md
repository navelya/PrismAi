# Note Node Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a non-runnable "note" node — a canvas annotation showing user-typed text plus the author's profile picture (name on hover) — added via an inline button in the node-library search-bar header.

**Architecture:** The note follows the `group_container` pattern exactly: a pure client-side UI node registered only in the shared registry (`nonExecutable: true`, no handles) and wired directly into the React Flow node-type map — NOT in the client/server plugin registries. Author identity is snapshotted into `node.data.config` at creation. Inline-editable text persists through the existing `updateNodeConfig` → workflow-save path.

**Tech Stack:** Next.js, React, React Flow, Zustand, Tailwind (design tokens), Supabase auth (for the author snapshot), framer-motion.

**Verification note:** This repo has **no test runner**. `npm run lint`/`npm run build` are unreliable here. The authoritative check is `npx tsc --noEmit`. Behavioral correctness is confirmed by manual E2E in the running app (Task 6).

### Task 2: Resolve the author avatar in `useCurrentUser`

`useCurrentUser` currently returns only `{ id, name }`. The note's avatar snapshot needs a URL. Extend it to also resolve `avatarUrl` (OAuth `avatar_url`/`picture` → `null`). This is additive, so existing consumers keep working.

**Files:**
- Modify: `lib/hooks/use-current-user.ts`

- [ ] **Step 1: Add `avatarUrl` to the resolved user**

Replace the body of `lib/hooks/use-current-user.ts` with:

```ts
'use client';
import { useEffect, useState } from 'react';
import { createClient } from '@/lib/supabase/client';

export function useCurrentUser() {
    const [user, setUser] = useState<{ id: string; name: string; avatarUrl: string | null } | null>(null);
    useEffect(() => {
        const supabase = createClient();
        supabase.auth.getUser().then((res: any) => {
            const u = res?.data?.user;
            if (!u) return;
            const meta = u.user_metadata || {};
            const emailName = (u.email || 'User').split('@')[0];
            const full = meta.full_name || meta.name || '';
            // Prefer a real first name (OAuth `given_name`, an explicit `first_name`,
            // or the first token of a full name); fall back to the email username.
            const first = meta.given_name || meta.first_name
                || (typeof full === 'string' && full.trim() ? full.trim().split(/\s+/)[0] : '')
                || emailName;
            // OAuth providers expose the avatar as `avatar_url` (Google/GitHub) or
            // `picture`. The custom profiles.avatar_url is intentionally NOT queried
            // here — falling back to OAuth/initials is acceptable for the note snapshot.
            const avatarUrl = meta.avatar_url || meta.picture || null;
            setUser({ id: u.id, name: first, avatarUrl });
        });
    }, []);
    return user;
}
```

### Task 3: The `NoteNode` component

A self-contained card (not `BaseNode`, which renders an output handle and run-status chrome we don't want). Renders no React Flow `<Handle>`s, an inline auto-sizing editable textarea, and the author avatar with name-on-hover.

**Files:**
- Create: `components/editor/NoteNode.tsx`

- [ ] **Step 1: Create the component**

Create `components/editor/NoteNode.tsx`:

```tsx
'use client';

import React, { memo, useCallback, useEffect, useRef, useState } from 'react';
import { NodeProps } from 'reactflow';
import { motion } from 'framer-motion';
import { User } from 'lucide-react';
import { cn } from '@/lib/utils';
import { useAppStore } from '@/lib/store/app-store';

interface NoteAuthor {
    id: string;
    name: string;
    avatarUrl: string | null;
}

interface NoteNodeData {
    label: string;
    config: {
        text: string;
        author: NoteAuthor | null;
    };
    isNew?: boolean;
}

function NoteNode({ id, data, selected }: NodeProps<NoteNodeData>) {
    const updateNodeConfig = useAppStore((s) => s.updateNodeConfig);
    const touchInteraction = useAppStore((s) => s.touchInteraction);

    // Reveal-on-settle gate (mirrors GroupNode/BaseNode): a freshly added node
    // held in aiTurn.hiddenAddedIds stays invisible until the end-of-turn
    // measured re-layout. Manual adds are never in that set, so they show now.
    const isHiddenForReveal = useAppStore((s) => !!s.aiTurn?.hiddenAddedIds?.includes(id));

    const author = data.config?.author ?? null;

    const textareaRef = useRef<HTMLTextAreaElement>(null);
    const isFocusedRef = useRef(false);
    const [draftText, setDraftText] = useState(data.config?.text || '');

    // Pull external text changes in only while not actively editing.
    useEffect(() => {
        if (isFocusedRef.current) return;
        const incoming = data.config?.text || '';
        if (incoming !== draftText) setDraftText(incoming);
    }, [data.config?.text, draftText]);

    // Auto-size the textarea to its content; capture wheel so the canvas doesn't
    // pan/zoom while the user scrolls a long note.
    useEffect(() => {
        const el = textareaRef.current;
        if (!el) return;
        el.style.height = 'auto';
        el.style.height = `${el.scrollHeight}px`;
        const onWheel = (e: WheelEvent) => { if (!e.ctrlKey && !e.metaKey) e.stopPropagation(); };
        el.addEventListener('wheel', onWheel, { passive: false });
        return () => el.removeEventListener('wheel', onWheel);
    }, [draftText]);

    const commitText = useCallback((next: string) => {
        if ((data.config?.text || '') === next) return;
        updateNodeConfig(id, { ...data.config, text: next });
    }, [id, data.config, updateNodeConfig]);

    const initial = (author?.name?.[0] || '?').toUpperCase();

    return (
        <motion.div
            initial={false}
            animate={{ opacity: isHiddenForReveal ? 0 : 1 }}
            transition={{ duration: 0.2 }}
            className={cn(
                'relative w-[220px] rounded-xl border bg-surface-elevated/90 backdrop-blur-sm shadow-lg transition-colors',
                selected ? 'border-accent-primary' : 'border-stroke-subtle',
            )}
        >
            {/* Author avatar — name revealed on hover via the native title tooltip. */}
            <div
                className="absolute -top-2.5 -left-2.5 z-10 w-6 h-6 rounded-full overflow-hidden ring-2 ring-surface-base bg-gradient-premium flex items-center justify-center text-white text-[10px] font-medium shadow"
                title={author?.name || 'Unknown author'}
            >
                {author?.avatarUrl ? (
                    <img src={author.avatarUrl} alt={author?.name || 'Author'} className="w-full h-full object-cover" />
                ) : author ? (
                    <span>{initial}</span>
                ) : (
                    <User className="w-3.5 h-3.5" />
                )}
            </div>

            <textarea
                ref={textareaRef}
                className="nodrag nowheel custom-scrollbar block w-full min-h-[48px] max-h-[280px] resize-none bg-transparent border-none p-3 pt-4 text-sm text-content-primary placeholder:text-content-tertiary focus:outline-none focus:ring-0"
                placeholder="Write a note…"
                value={draftText}
                onChange={(e) => { touchInteraction(); setDraftText(e.target.value); }}
                onFocus={() => { isFocusedRef.current = true; }}
                onBlur={() => { isFocusedRef.current = false; commitText(draftText); }}
                onKeyDown={(e) => { if (e.key === 'Backspace' || e.key === 'Delete') e.stopPropagation(); }}
            />
        </motion.div>
    );
}

export default memo(NoteNode);
```
